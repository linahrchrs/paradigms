# SOAP Log Analysis System

A client-server application for analyzing Apache Common Log Format (CLF) files using SOAP/XML protocol. The server is implemented in Python and the client in Java, demonstrating language-independent remote procedure calls.

## Features

- **Count Requests**: Count total number of log entries in a file
- **Status Distribution**: Get distribution of HTTP status codes (200, 404, 500, etc.)
- **SOAP Protocol**: Uses standardized SOAP/XML for communication
- **Language Independence**: Python server ↔ Java client
- **Error Handling**: Structured SOAP faults for file errors

## Prerequisites

### Server Requirements
- Python 3.10 or Python 3.11
- pip (Python package manager)

### Client Requirements
- Java JDK 11 or higher
- Maven or Maven Daemon (mvnd)

## Installation

### 1. Install Python Dependencies


```bash
python3.10 -m pip install spyne lxml
# or
python3.11 -m pip install spyne lxml
```

### 2. Setup Java Project Structure

Ensure your project has the Maven structure:

```bash
mkdir -p src/main/java

```

### 3. Verify Maven/Maven Daemon Installation

```bash

mvnd --version

# Or check standard Maven

```

If not installed, install Maven Daemon or standard Maven from:
- Maven Daemon: https://github.com/apache/maven-mvnd
- Maven: https://maven.apache.org/download.cgi

## Usage

### Step 1: Start the Python Server

Navigate to the `P1` directory and start the server:

```bash
# Navigate to P1 directory
cd P1

# Using default Python
python soap_server.py

# Or using specific Python version
python3.10 soap_server.py
# or
python3.11 soap_server.py
```

You should see:
```
SOAP Server running on http://localhost:7500
WSDL available at: http://localhost:7500/?wsdl
```

**Keep this terminal open!** The server must be running for the client to connect.

### Step 2: Build the Java Client

In a **new terminal**, navigate to the `log-analysis-client` directory and build:

```bash
# Navigate to the Maven project
cd log-analysis-client

# Clean and compile
mvnd clean compile

# Package into executable JAR
mvnd clean package
```

This creates:
- `target/log-analysis-client-1.0-SNAPSHOT-jar-with-dependencies.jar`

### Step 3: Run the Java Client

Make sure you're in the `log-analysis-client` directory.

#### Option A: Using Maven Exec (Development)

```bash
# Count requests (using access.log from P1 directory)
mvnd exec:java "-Dexec.mainClass=LogAnalysisClient" "-Dexec.args=count ../P1/access.log"

# Or using access_clean.log
mvnd exec:java "-Dexec.mainClass=LogAnalysisClient" "-Dexec.args=count ../P1/access_clean.log"

# Status distribution
mvnd exec:java "-Dexec.mainClass=LogAnalysisClient" "-Dexec.args=status ../P1/access_clean.log"
```

**Note for PowerShell users**: The quotes around `-D` arguments are required!

#### Option B: Using Executable JAR (Recommended)

```bash
# Count requests
java -jar target/log-analysis-client-1.0-SNAPSHOT-jar-with-dependencies.jar count ../P1/access.log

# Status distribution
java -jar target/log-analysis-client-1.0-SNAPSHOT-jar-with-dependencies.jar status ../P1/access_clean.log
```

**Note**: The log files are in the `P1` directory, so use relative path `../P1/` or provide absolute path.


## Expected Output

### Count Command
```bash
$ java -jar target/log-analysis-client-1.0-SNAPSHOT-jar-with-dependencies.jar count test.log
Total requests: 5
```

### Status Command
```bash
$ java -jar target/log-analysis-client-1.0-SNAPSHOT-jar-with-dependencies.jar status test.log
Status Code Distribution:
  200: 3 occurrences
  404: 1 occurrences
  500: 1 occurrences
```


### SOAP Endpoints
- **WSDL**: http://localhost:7500/?wsdl
- **Service**: http://localhost:7500/loganalysis

### Operations
1. **countRequests**
   - Input: filename (string)
   - Output: total count (integer)
   - Fault: FileNotFoundFault

2. **statusDistribution**
   - Input: filename (string)
   - Output: Array of StatusEntry (statusCode, count)
   - Fault: FileNotFoundFault

### Protocol
- SOAP 1.1
- Document/Literal style
- HTTP transport
- XML serialization
